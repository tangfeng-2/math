# 圆的认识 · 互动数学课堂

面向小学数学课堂的单文件 HTML 课件，支持投屏演示、鼠标点击和触屏拖动。无需安装依赖或连接网络。

## 打开课件

1. 下载本仓库并解压，或单独保存 `index.html`。
2. 用浏览器打开 `index.html`。
3. 点击顶部教学环节切换内容；投屏时可点击「全屏授课」。若浏览器不支持页面全屏按钮，可使用浏览器的全屏菜单。

## 手机和平板使用

- 手机竖屏使用三列导航，圆形画布放大显示；平板和桌面自动调整布局。
- 按钮至少 44 像素高，滑块和圆上的拖动点扩大了触控区域。
- 手指画线时，圆心与圆周采用更大的吸附范围；从画布外滑动可滚动页面。
- 手机端优先显示操作工具，再显示知识说明；横竖屏切换保留当前绘图。
- 已在浏览器中检查 320、390、768、1280 像素宽度的布局，并验证窄屏拖动画线；实际手机触屏体验仍需在设备上确认。

## 教学环节

| 环节 | 主要操作与内容 |
| --- | --- |
| 认识圆 | 显示或隐藏圆心、半径、直径；拖动圆上的点或点击「换个方向」，观察半径。 |
| 圈出圆 | 从生活物体的轮廓中找出圆形，获得即时反馈。 |
| 折一折 | 演示对折、展开与换方向，理解圆的对称轴。 |
| 画一画 | 调整圆规开口，观看画圆动画；半径可选 1～4 厘米，步长为 0.5 厘米。 |
| 量一量 | 改变半径，观察直径，理解同一个圆中 `d = 2r`。 |
| 挑战一下 | 完成 5 道知识题；答错可重试，答对后可进入下一题。 |
| 读一读，画一画 | 阅读圆心、半径和直径的定义，在圆内画线段并比较长度。 |

## 画线段操作

进入第 7 项「读一读，画一画」：

- 在圆内按住鼠标或手指拖动，松开后完成一条线段。
- 端点靠近圆心或圆周时会自动吸附，右侧实时显示线段长度。
- 最多保留两条线段，可点击「撤销上一条」或「清除画面」。
- 键盘操作：将焦点移到画布，用方向键移动光标，按回车确定起点和终点，按 `Esc` 取消当前绘制。

课堂示例：从圆心画到圆周，再画一条经过圆心、两端位于圆周的线段，比较两者的长度。此环节的圆半径固定为 5 厘米，半径与直径应分别为 5 厘米和 10 厘米。

## 使用说明

- 页面中的厘米是教学示意单位，不代表屏幕上的实际物理尺寸。
- 点击「重新探索」、切换环节或刷新页面会重置相关操作；课件不保存作答或绘图记录。
- HTML 内已包含样式、脚本和图形，可单独复制到上课电脑使用。

## 文件与检查

- `index.html`：完整互动课件。
- `check.cjs`：使用 Node.js 内置模块运行的逻辑检查，无需安装第三方包。

在仓库目录执行：

```sh
node check.cjs
```

检查覆盖七个环节的基础渲染、半径与直径计算、题目答案，以及画线吸附、长度、数量限制、撤销、清除、取消、多触点和键盘操作逻辑。检查使用模拟 DOM，不代替真实浏览器的布局与触屏验收。
